# Chess piece artwork credits

M-Chess offers 21 distinct chess piece sets. These are different original designs, not CSS recolors of a handful of source sets.

Piece SVGs are loaded at runtime from the Lichess repository: https://github.com/lichess-org/lila/tree/master/public/piece

## Important

The app fetches artwork directly from the Lichess repository; it does not repackage the SVG files in this repository. Licenses differ between sets. CC BY-NC-SA sets are not suitable for commercial use, and other sets marked “verify” should not be assumed unrestricted. Before publishing or monetizing the app, inspect the original license and attribution notices for every set you keep. This file is a provenance guide, not legal advice or a guarantee of unrestricted use.
