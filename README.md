# M-Chess ♟️

Карточные шахматы: играй против компьютера, открывай двери и меняй правила битвы с помощью магических карт.

## Первый прототип
- Локальная игра без сервера и регистрации.
- Шахматы против простого компьютерного соперника.
- После каждого хода открывается одна карта двери.
- Зелья временно меняют движение фигур, броня защищает от первого взятия.
- Состояние игры хранится только в браузере.

## Запуск
```bash
npm install
npm run dev
```

## Первые правила карт
- **Зелье рывка:** пешка может пройти до трёх клеток вперёд в свой следующий ход, если путь свободен.
- **Зелье превращения:** конь ходит как ферзь в свой следующий ход, но не может перепрыгивать через фигуры.
- **Броня:** следующий удар по выбранной фигуре блокируется, броня после этого исчезает.
- **Дверь-ловушка:** случайная своя фигура получает запрет на взятие до начала следующего хода.

Это ранний прототип: эффекты будут уточняться и балансироваться по мере тестирования.
